# Franka Writing Studio v1.1.0

v1.1.0 turns the validated Franka Writing Studio into an interactive manipulator digital-twin demo while preserving the existing robotics execution stack.

## Highlights

- Draw directly in the dashboard with a mouse, touchscreen, or stylus.
- Load supported SVG geometry through the same common input pipeline.
- Preserve multiple ordered strokes and explicit pen-up transfers.
- Plan and validate every drawing before execution.
- Execute through the existing `RobotInterface`, hybrid Cartesian controller, damped least-squares differential IK, and PyBullet simulation.
- Observe live path, force, contact, error, progress, and state telemetry.
- Retain the completed PyBullet scene for post-run inspection.
- Use Isometric, Top, Notebook, and Robot camera presets plus orbit, tilt, zoom, and pan controls.
- Record PyBullet execution video and the Live Engineering Telemetry window independently or simultaneously.

## Architecture

```text
DRAW ------------------+
                       |
                       +--> DrawingDocument
                       |         |
SVG --> SVG adapter ---+         v
                         drawing_to_waypoints
                                 |
                                 v
                         TimedWritingPlan
                                 |
                                 v
                              validate
                                 |
                                 v
                           RobotInterface
                                 |
                                 v
                    hybrid Cartesian control
                                 |
                                 v
                              PyBullet
```

The freehand feature is an input generalization, not a second robot-control pipeline.

## Scope and Limitations

This remains a simulation-only robotics project. The release does not claim physical Franka deployment, real-world submillimeter accuracy, safety certification, ROS 2 integration, PLC integration, perception, physical system identification, or online adaptive control.

The physical pen model remains rigidly attached to the simulated end effector, and collision preflight is sampled rather than continuous.
